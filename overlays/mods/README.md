# Mods

Optional overlays composed into a build via `-<name>` in `PROFILE`. Most are
personal and unmaintained; maintained project mods include `ace`, `devel`, and
`qemu`. For example, `overlays/mods/ace/` is selected by `extended-ace`.

See [docs/mods.md](../../docs/mods.md) for naming conventions and the
rules around contributing your own mod.
